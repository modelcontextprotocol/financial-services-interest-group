# Exploratory extensions

Before building an extension, open or find an [FSIG issue](https://github.com/modelcontextprotocol/financial-services-interest-group/issues) describing the financial-services problem. Explain which existing MCP primitives you tried and what requirement remains unmet. For feedback or help finding the relevant WG, bring the issue to [#financial-services-ig](https://discord.gg/6CSzBmMkjX).

Use this directory only when triage identifies a specific question that a prototype can answer. Agree on the scope and relevant WG in the issue. Once a facilitator or maintainer approves the experiment and assigns the issue, [open a linked PR](../CONTRIBUTING.md#opening-a-pull-request). Record what the experiment showed so the group can decide where the work belongs.
